# DDCAの授業利用例と出典

[スライドに戻る](中間発表_主要事項.md#slide-13)

DDCA（Digital Design and Computer Architecture、日本語書名『ディジタル回路設計とコンピュータアーキテクチャ』）が、授業の教科書・教材・参考書として掲載された例を集めた。日本語版と英語版、MIPS版・ARM版・RISC-V版などを含む。

**22機関・14都道府県で掲載例を確認した。** 高専4機関、大学の学部14機関、大学院6機関である。東京大学と広島大学には学部・大学院の両方の例があるため、区分別の機関数の合計24からこの重複2機関を引き、全体を22機関と数える。

確認日：2026年10月26日。年度が分かる資料は2019〜2026年度である。開志専門職大学と長崎大学の資料には授業年度が明記されていない。京都大学は2026年度授業ページからリンクされている資料を確認した。過去の例も含めた分布であり、全校を同じ年度で比較した統計ではない。

## 地図の読み方

- 日本地図は1枚とし、高専は青、大学（学部）は橙、大学院は緑で塗る。同じ都道府県で複数の区分を確認した場合は、それらの色の縞模様にする。縞の面積比は学校数を表さない。
- 区分は学校名ではなく授業の対象課程で決める。大学院を持つ大学でも、学部の授業は「大学（学部）」に入れる。
- 所在地は授業のキャンパス・開催地を基準とする。たとえば総合研究大学院大学の公開講義は、大学本部の神奈川県ではなく、会場の茨城県に入れる。
- 灰色は、この一覧で掲載例を確認できていない都道府県を示す。DDCAを使う学校がないという意味ではない。
- 地図は教材として挙げられている地域の広がりを示す。全国の採用校を網羅しておらず、採用率や市場シェアは算出していない。
- 教科書と参考書は下表で区別する。参考書への掲載だけから、授業で毎回使うことや学生全員の購入は分からない。過去の指定が現在も続いているとは限らない。

## 探し方と収録条件

日本語書名、英語書名、DDCA、著者名Harris・ハリスと、授業・シラバス・教科書・参考書を組み合わせて検索し、高専のシラバス、大学・大学院の公式シラバス、公式授業ページ、過去年度の授業資料を確認した。現在の公開情報だけに絞らず、検索できる過去の掲載も対象とした。

授業名とDDCAの関係を公式資料で確認できるものを収録した。一般の蔵書検索や書店の販売情報だけでは収録しない。高知大学大学院の資料は科目名とシラバス掲載図書を対応づけた公式一覧であり、単なる蔵書検索とは異なる。長崎大学の資料は公式学部サイトにある個別授業の紹介である。

非公開シラバス、検索に出ないページ、削除された過去資料などは拾えない。この一覧を「日本の採用校のすべて」と説明することはできない。

## 質問への説明例

「DDCAは、高専・大学の学部・大学院の授業で、教科書や参考書として挙げられています。過去の指定も含めて、公開資料から22機関・14都道府県で確認できました。この地図はその地域の広がりを示します。すべての採用校を調べたものではありません。」

DDCAの掲載例は、RVSOCの採用実績や本研究による教育効果を直接示すものではない。研究の背景にある教科書が、各種の教育課程で教材として挙げられていることを裏付ける資料である。
