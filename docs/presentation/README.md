# 中間発表

[PowerPointを開く](中間発表_主要事項.pptx) / [スライドと発表原稿を読む](中間発表_主要事項.md)

アブストに沿って、FPGAを用いた2Dゲーム機の製作を説明します。
Wallyを紹介した後、SDカードへの要求と受信から説明し、DDR3への保存と実行へ進みます。
動作確認は動画の1枚にまとめ、追加した回路とソフトウェアを独立した1枚で示します。
2〜11枚目は同じFPGAボードの図を使い、チップとSDスロット・DDR3メモリ・HDMI端子の位置を保ちます。
4枚目でWallyの箱の中身を展開し、その後も回路と信号線を動かさずに説明します。
7枚目では6枚目のDDR3への書込みにSDからの読出しを加え、二つを交互に繰り返すコピー処理へ進みます。
表紙1枚、発表用12枚、移動用の目次1枚、非表示の質問用スライド13枚です。

質問用の地図は、過去の指定を含む22機関・14都道府県の掲載例を、1枚の日本地図にまとめています。
年度が分かる資料は2019〜2026年度で、年度不明の公式資料も2件含みます。
同じ都道府県に複数の区分がある場合は縞模様にしています。
[教育機関・授業・年度・教科書／参考書の区分と出典](DDCA授業利用の出典.md)をまとめています。
灰色は未確認であり、全国の採用校を網羅した地図ではありません。

質問用の使用量は、描画機能追加前のWally構成（Before：2026年9月8日）と、開発時の実験E8の描画・表示機能付き構成（After：2026年11月8日）の使用率を比較しています。
どちらも同じFPGAの配置配線後の記録です。Afterは開発時の表示構成で、今回の動画の標準表示構成とは異なります。開発前後の回路全体の比較であり、差を描画回路単体の使用量とするものではありません。
[比較資料と元レポート](../../experiments/fpga-resource-comparison-20261108/README.md)から数値と比較範囲を確認できます。

RVSOCの質問用スライドでは、教科書の指定・使用実績が確認できた3校をまとめています。
出版前の原稿を使った過去の授業を含み、現在の全採用校を網羅した一覧ではありません。
[教育機関・時期・採用の根拠と出典](RVSOC教科書採用の出典.md)を参照できます。

動作確認は、最新のアブストと同じ2026年11月9日の実機記録で説明します。
RasterIX同梱の描画・表示回路を使い、「ボールが動く・跳ね返る・ブロックが消える」ことを確認しました。
[構成・記録・確認できた範囲](../../experiments/dvi-recovery-20261109/README.md)を参照できます。
