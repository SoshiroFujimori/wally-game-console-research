[図の出典と生成方法](../../source/presentation/README.md)

質問用の地図は、過去の指定を含む22機関・14都道府県の掲載例を、1枚の日本地図にまとめています。
年度が分かる資料は2019〜2026年度で、年度不明の公式資料も2件含みます。
同じ都道府県に複数の区分がある場合は縞模様にしています。
[教育機関・授業・年度・教科書／参考書の区分と出典](DDCA授業利用の出典.md)をまとめています。
灰色は未確認であり、全国の採用校を網羅した地図ではありません。

質問用の使用量は、描画機能追加前のWally構成（Before：2026年9月8日）と、動画にも使った実験E8の描画・表示機能付き構成（After：2026年11月8日）の使用率を比較しています。
どちらも同じFPGAの配置配線後の記録です。開発前後の回路全体の比較であり、差を描画回路単体の使用量とするものではありません。
[比較資料と元レポート](../../experiments/fpga-resource-comparison-20261108/README.md)から数値と比較範囲を確認できます。

RVSOCの質問用スライドでは、教科書の指定・使用実績が確認できた3校をまとめています。
出版前の原稿を使った過去の授業を含み、現在の全採用校を網羅した一覧ではありません。
[教育機関・時期・採用の根拠と出典](RVSOC教科書採用の出典.md)を参照できます。

動作確認は、2026年11月8日に実機から記録した動画で「ボールが動く・跳ね返る・ブロックが消える」場面を説明します。[確認場面と試験条件](../../experiments/basic-operation-20261108/README.md)を参照できます。5分間の実行記録や内部の処理回数の説明は、本編の発表内容に含めていません。

描画回路の質問用スライドは、2026年11月8日に確認した公式RasterIXの「FPGA pipeline」図を横長に描き直しています。最新公式図には実機と異なる構成が含まれるため、実機がTMU 1基・TextureBuffer方式であることを図の下に記しています。[元図・版・再構成の範囲](../../source/presentation/rasterix-pipeline/README.md)を参照できます。

以前の命令の実行から説明する版は、[変更前のコミット](https://github.com/SoshiroFujimori/wally-game-console-research/tree/40d8a51bd1ab0d9c9a469146c349cd31b173bdce/docs/presentation)から参照できます。
