# 中間発表

[PowerPointを開く](中間発表_主要事項.pptx) / [スライドと発表原稿を読む](中間発表_主要事項.md)

FPGAを用いた2Dゲーム機の製作を説明します。
本編11枚と、非表示の質問用スライド5枚です。

| スライド | 内容 |
| --- | --- |
| 1 | 表紙 |
| 2 | FPGAチップに回路を実装し、ボード上の部品を制御する |
| 3 | 教育用CPUに描画機能を追加し、ゲーム機への拡張例を示す |
| 4 | FPGA内のメモリから値を読むlw命令 |
| 5 | 同じ図で、レジスタの値をメモリへ書くsw命令 |
| 6 | バスとAMD提供のDDRコントローラーを追加 |
| 7 | SDカードのプログラムをDDR3へ移す処理 |
| 8 | 描画回路への描画命令の送信 |
| 9 | 画像の保存とHDMI端子への出力 |
| 10 | ブロック崩しの実機動画と動作確認 |
| 11 | 結論と今後のゲームコントローラ接続 |
| 12 | 質問用：詳細な全体のブロック図 |
| 13 | 質問用：DDCAを教科書・参考書に挙げる教育機関の日本地図 |
| 14 | 質問用：FPGAチップの構成要素（ロジックセルと専用回路） |
| 15 | 質問用：FPGAの使用量（実機で使用した回路全体） |
| 16 | 質問用：RVSOCの教科書採用例（原稿版の使用を含む） |

スライド10の動画はPowerPointに埋め込んでいます。
スライドショー中に動画の領域をクリックして再生します。
[同じ30秒の動画](../../experiments/basic-operation-20261108/video/breakout-30s.mp4)を個別に開くこともできます。
現在は自動プレイで、ゲームコントローラの操作映像ではありません。

[図の出典と生成方法](../../source/presentation/README.md)

質問用の地図は、過去の指定を含む22機関・14都道府県の掲載例を、1枚の日本地図にまとめています。
年度が分かる資料は2019〜2026年度で、年度不明の公式資料も2件含みます。
同じ都道府県に複数の区分がある場合は縞模様にしています。
[教育機関・授業・年度・教科書／参考書の区分と出典](DDCA授業利用の出典.md)をまとめています。
灰色は未確認であり、全国の採用校を網羅した地図ではありません。

質問用の使用量は、動画と同じ実験E8のHDMI表示構成で、2026年11月8日に配置・配線した後の記録です。
[使用数・搭載数・使用率の元データ](../../experiments/basic-operation-20261108/results/implementation.json)の`resources`欄から生成します。

RVSOCの質問用スライドでは、教科書の指定・使用実績が確認できた3校をまとめています。
出版前の原稿を使った過去の授業を含み、現在の全採用校を網羅した一覧ではありません。
[教育機関・時期・採用の根拠と出典](RVSOC教科書採用の出典.md)を参照できます。

動作確認は、2026年11月8日に実機から記録した動画で「ボールが動く・跳ね返る・ブロックが消える」場面を説明します。[確認場面と試験条件](../../experiments/basic-operation-20261108/README.md)を参照できます。5分間の実行記録や内部の処理回数の説明は、本編の発表内容に含めていません。
