# 中間発表資料

[PowerPointを開く](中間発表_主要事項.pptx) / [スライドと発表原稿を読む](中間発表_主要事項.md)

本編は表紙1枚と発表用8枚の計9枚です。その後に目次1枚と回答用15枚が続き、ファイル全体は25枚です。背景、本研究の概要、ソフトウェア、ハードウェア、実行結果、まとめの順に説明します。

## 構成

| スライド | 区分 | 内容 |
| --- | --- | --- |
| 1 | 表紙 | FPGAを用いた2Dゲーム機の製作 |
| 2 | 背景 | FPGAとは |
| 3 | 背景 | 先行研究と教育現状 |
| 4 | 本研究の概要 | 本研究の概要 |
| 5 | ソフトウェアの概要 | ソフトウェアの概要 |
| 6 | ハードウェアの概要 | ハードウェア：アドレスの割当て |
| 7 | 実行結果 | 実行結果：FPGAチップの使用量 |
| 8 | 実行結果 | 実行結果：ブロック崩しの動画 |
| 9 | まとめ | まとめと今後の展望 |

3枚目では、CPUと複数の周辺回路を含む既存構成と、別のFPGAにある描画回路を示します。SDカード制御回路はスロットを通じてカードへ接続します。CPUはカードのプログラムをDDRメモリへ読み込み、実行します。RVSOCの採用大学も紹介し、CPUや周辺回路の設計を学ぶ需要がうかがえると説明します。

4枚目は同じ配置の図で、追加した描画回路とSDカード上のブロック崩しを青色にします。5枚目はDDRメモリへの通常の書込みと描画命令の送信をCの概念例で比較し、6枚目は各周辺回路へのイネーブル信号を示します。まとめも同じ回路図を用います。

実行結果は使用量、動画の順です。7枚目はWallyの基本構成とゲーム機構成の使用率、8枚目は自動プレイの30秒の実機映像です。計画上の時間配分は動画を含め330秒で、練習を実測した時間ではありません。

## 実機動画と使用量

8枚目には[実機動画](../../source/presentation/assets/breakout-standard-dvi-compatible.mp4)を埋め込んでいます。PowerPointのスライドショーで自動再生します。ゲーム画面は最新の文字配置を使った記録で、自動操作です。ブロックの消去と、ブロック・バーでのボールの反射を確認しています。

回路の版・記録条件は[実機記録](../../experiments/dvi-recovery-20261109/README.md)、使用量は[構成とレポートの対応](../../experiments/standard-display-resources-20261110/README.md)を参照できます。使用量はCPUや周辺制御を含む構成全体の比較です。差のすべてを描画回路単体の使用量とはしていません。
