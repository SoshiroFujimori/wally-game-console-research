# 中間発表

[PowerPointを開く](中間発表_主要事項.pptx) / [スライドと発表原稿を読む](中間発表_主要事項.md)

既存のCPUと描画回路を接続し、ブロック崩しの動作を確認した研究を説明します。CPUを「Wally」、回路の提供元を「Wallyリポジトリ」と表記します。

まず[発表の要点](発表の要点.md)で、目的、追加した接続、確認した動作を読めます。[OpenGLの説明と想定質問](OpenGLの説明と想定質問.md)には、図形・文字の描き方と、実装に基づく28の質問と回答をまとめています。

発表用スライドは「背景→本研究の概要→ソフトウェアの概要→ハードウェアの概要→実行結果→まとめ」の順です。各ページの右上に区分を示します。実行結果では、11枚目にFPGAの使用量、12枚目にブロック崩しの動画を示します。

5枚目はCPUと周辺制御回路を一つの箱にまとめ、接続部分とゲームプログラムを追加した範囲を示します。6枚目のC言語の概念例から、7枚目のMMIO、8枚目のアドレスデコーダ、9枚目の接続回路へ説明を進めます。10枚目は画像の保存と映像出力を示します。ボード、チップ、周辺部品の配置を保ち、注目する経路を青く示します。

## 先行研究と既存の実装

3枚目では、FPGAにCPUや描画回路を実装する先行研究・開発を紹介します。CPUの例にWally、描画・表示の例にRasterIXを挙げます。図はそれぞれの既存回路を紹介するもので、両者を接続した先行事例を示すものではありません。Wallyの教材とFPGA実装は[ASEE論文](https://doi.org/10.18260/1-2--57147)、RasterIXは[公式リポジトリ](https://github.com/ToNi3141/RasterIX)を根拠にしています。

## 教科書と研究目的

4枚目は、値の保存・計算・制御の回路からCPUを作る学習、CPUにメモリや周辺回路をつなぐ学習、描画・表示を加える本研究の関係を、3つの簡略図で示します。『ディジタル回路設計とコンピュータアーキテクチャ』について4校、『RISC-V SoC設計』について3校の教科書指定・使用例を掲載します。過去の例も含みます。後者は英語書名を説明用に日本語で表したものです。国内でのDDCAの教科書指定とRVSOCの授業での使用を背景に、Wallyの学習者へゲーム機の拡張例を提供する目的を説明します。教育効果の実測結果としては扱いません。

## 読込みから描画命令の送信まで

6枚目は、左にSDカードからの読込み、右にDDRメモリへ読み込んだゲームを、行番号付きのC言語の概念コードで示します。6行目で受信した1バイトをDDRメモリへコピーし、7行目でコピー先のゲームを呼び出します。ゲームは描画命令を用意し、13〜14行目で送信口へ書き込みます。

7枚目に13〜14行目を再掲し、その書込みを受ける回路を8・9枚目で説明します。アドレスやポインタの意味、概念例で省略した処理は、スライドの補足説明と[発表の要点](発表の要点.md)にまとめています。C言語の文字列をSDカードから直接実行するという説明ではなく、コンパイルされた機械語をDDRメモリへ読み込み、CPUで実行する流れを示しています。

アドレスデコーダが接続先を選び、接続回路が通信方式とクロック周波数の違いに対応する様子を説明します。

## 実機動画

30秒の動画を12枚目に埋め込んでいます。スライドショーで12枚目に進むと自動再生します。[同じ動画](../../source/presentation/assets/breakout-standard-dvi-compatible.mp4)を個別に開くこともできます。

RasterIX同梱の描画・表示回路を使い、図形と文字の表示、ボールとパドルの移動、ブロック消去、得点更新を示します。パドルは自動操作です。録画のフレームレートを、ゲームが新しい画像を作るFPSとしては報告しません。

配布用の動画は互換性のある形式へ再符号化しています。[実機記録の原本](../../experiments/dvi-recovery-20261109/media/latest-standard-dvi-30s.mp4)と、[構成・記録・確認できた範囲](../../experiments/dvi-recovery-20261109/README.md)も参照できます。

## 回答用資料の出典と範囲

OpenGLの説明は、使用したゲームとRasterIXの版を固定して、座標・RGBAの値・呼び出した関数から説明しています。文字の画像を用意する操作と、その画像を画面へ貼る操作を順に追えます。VBOや固定機能API、CPUと回路の分担についての質問には、[想定質問と実装へのリンク](OpenGLの説明と想定質問.md)を使えます。

DDCAの地図は、過去の指定を含む22機関・14都道府県の掲載例を、1枚の日本地図にまとめています。年度が分かる資料は2019〜2026年度で、年度不明の公式資料も2件含みます。同じ都道府県に複数の区分がある場合は縞模様にしています。灰色は未確認であり、全国の採用校を網羅した地図ではありません。[教育機関・授業・年度・教科書／参考書の区分と出典](DDCA授業利用の出典.md)を参照できます。

RVSOCの回答用スライドは、教科書の指定・使用実績が確認できた3校をまとめています。出版前の原稿を使った過去の授業を含みます。[教育機関・時期・採用の根拠と出典](RVSOC教科書採用の出典.md)に確認した範囲を記しています。

11枚目は、元のWally基本構成と、動画と同じ標準表示のゲーム機構成のFPGA使用量を並べます。どちらもCPUと周辺回路を含みます。ゲーム機構成の配置配線後のレポートでは、LUT 49.90%、Slice Registers 18.90%、Block RAM Tile 58.90%、DSP 8.24%です。CPUやメモリ制御を含む、回路全体の値です。

比較の対象は、以前保存したCPU・周辺回路の構成（Before：2026年9月8日）と、このゲーム機構成（After：2026年10月8日）です。CPUの版や設定を固定した比較ではないため、差を描画回路単体の使用量とはしません。[使用量の根拠・比較範囲・元レポート](../../experiments/standard-display-resources-20261110/README.md)に、動画との対応も記しています。

18枚目は、命令の実行から周辺回路への接続までを1枚の図にまとめています。PC・命令メモリの箱・レジスタ群・ALU・データメモリの箱の並びを保ち、二つの接続口から出るAD・WD・WEを要求の選択回路へつなぎます。その先にアドレスデコーダ、SDカード制御、DDRメモリ制御、描画用の接続回路を置き、RDをCPUへ返す経路、画像をDDR3に保存して表示する経路も示します。

描画回路のFPGAパイプライン図は、2026年11月8日に確認した公式RasterIXの図を横長に描き直しています。元図には実機と異なる構成が含まれるため、実機がTMU 1基・TextureBuffer方式であることを図の下に記しています。[元図・版・再構成の範囲](../../source/presentation/rasterix-pipeline/README.md)を参照できます。
