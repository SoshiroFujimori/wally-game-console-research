# FPGAを用いた2Dゲーム機の製作

## 1  はじめに

FPGAは，コードで記述した論理回路を実装できる半導体チップである．本研究では，教育用CPU「Wally」[1]に描画・表示機能を追加し，ブロック崩しが動くゲーム機を製作した．Wallyの学習者に，ゲーム機への拡張例を示すことを目的とする．

## 2  ゲーム機の設計

図1にCPUと周辺回路の接続を示す．Wallyの回路に，RasterIX[2]の描画・表示機能を流用し，接続回路を加えた．これらをNexys VideoのFPGAに実装した．

![FPGAボード内にFPGAチップと，チップ外のSDカードスロット，DDR3メモリ，HDMI端子を示す．右側の3部品を共通の枠で囲み，「枠内の3点は基板に実装済み」と示す．ゲーム入りのカードを挿す説明はSDカードスロットの枠内に，保存するプログラムと画像はDDR3メモリの枠内に，画面へ映像を送り出す説明はHDMI端子の枠内に配置する．チップ内では，CPUのアドレスADをデコーダ①へ渡し，ADの属する範囲からSD制御（S0），DDR制御（S1），接続回路（S2）の一つを選ぶ．SD制御の範囲は0x13000〜0x13FFF，DDR制御は0x80000000〜0x9FFFFFFF，接続回路は0x10080000〜0x100800FFである．SD制御回路②の内部には0x13048の送信用と0x1304Cの受信用の場所を示す．複数のアドレスが同じ回路を選び，その回路内の操作先を指定する．書込みデータWDと1ビットの書込みイネーブルWEを各回路へ渡し，読出しデータRDを選んでCPUへ返す．WEは0で読出し，1で書込みを意味する．接続回路は描画命令をRasterIXへ渡す．RasterIXの描画と表示を一つの箱にまとめ，DDR3との画像の読み書きとHDMI端子への映像出力を示す．WallyリポジトリとRasterIXの流用範囲を破線で囲む．細線は1ビット，太線は複数ビット，黒丸は接続点である．回路をHDLで記述することと，DDR3にプログラムと画像を保存することを補足する．タイミング制御を省略した概念図である．](figs/figure-1.png)

図1  回路の接続とアドレスの割当

各回路にはアドレス範囲を割り当て，デコーダ①がADの属する範囲から回路を選ぶ．選ばれた回路は，ADから内部の操作先を決める．SD制御回路②では，0x13048は送信用，0x1304Cは受信用の場所（レジスタ）を指す．いずれも同じ回路内の場所である．WEは1ビットの書込みイネーブルで，1ならWDを書き込み，0なら選択回路を通ったRDを読む．

CPUはSDカードに「ゲームの保存位置からデータを送れ」と指示する．その指示を表す数値列を，送信用アドレス0x13048へ順に書くと，SD制御回路がカードへ送る．CPUは届いたデータを同じ受信用アドレス0x1304Cから繰り返し読み，DDR3へ保存する．保存先のアドレスはDDRコントローラーを選ぶとともに，DDR3内の位置を指定する．受信用アドレスは固定し，保存先を1バイトずつ進める．

ゲームは，RasterIX付属のOpenGL互換ライブラリに図形の位置や色を渡す．CPU上で動くライブラリは，描かせる内容を数値列にする．CPUが0x10080000へその数値を書くと，接続回路の描画命令用の書込み先が選ばれ，描画回路へ数値を渡す．

コード1のsd_start_readは，ゲームの保存位置からの送信をカードに指示する説明用の関数である．初期化や受信のための通信手順は省略した．sizeバイトを保存後，start()でプログラムの先頭へ分岐する．先頭はDDR3上の0x80000000と仮定した．

```c
// SDカードへゲームデータの送信を指示
sd_start_read(game_position);
uint8_t *dst = (uint8_t *)0x80000000;
// 読出し先は固定し，保存先だけ進める
for (int i = 0; i < size; i++) {
  dst[i] = *(uint32_t *)0x1304C;
}
// 保存したプログラムの先頭へ分岐
void (*start)(void) = (void (*)(void))0x80000000;
start();
// ゲーム側の抜粋：描画回路へ命令を送る
*(uint32_t *)0x10080000 = cmd;
```

コード1  読込み・実行・描画の概念コード

RasterIXは，描画命令に従って画像を作り，DDRコントローラーを介してDDR3へ保存する．さらに，その画像を読み出し，HDMI端子へ映像を出す．RasterIX本体は変更していない．

## 3  動作の確認

実機で640×480画素のブロック崩しを実行し，HDMI端子から出力した映像を確認した（図2）．ボールが動き，壁やパドルで跳ね返り，当たったブロックが消えることを確認した．

現在はプログラムがパドルを動かす自動操作であり，ゲームコントローラによる操作は未実装である．

## 4  おわりに

Wallyを拡張し，ブロック崩しの実行と映像出力を実現した．回路の接続とゲームの動かし方を公開した．今後は，ゲームコントローラへの対応やホーム画面などのGUIの充実を検討する．

図2は[標準表示構成の実機記録](../../experiments/dvi-recovery-20261109/README.md)の画像である．描画と表示にはRasterIX同梱の回路を流用し，命令転送や表示切替えを仲介する回路を本研究で接続した．DDRコントローラーはAMD製IPで，その生成・接続設定はWally側に含まれる．
