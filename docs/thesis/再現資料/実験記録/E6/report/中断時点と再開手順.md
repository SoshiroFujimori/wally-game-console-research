## 再開時にすること

1. 基板の電源・JTAG・UART・SDWireの状態を確認する。今回起動した専用hw_serverは中断時に終了したので、必要なら起動し直す。
2. 基板がリセットされていれば、上記の通常版ビットストリームを書き込み、起動を確認する。
3. 実験ルートで `python3 scripts/run-game-matrix-v2.py latest` を実行し、同じ測定プログラムをSDから読み、ハッシュと全画面の一致を確かめる。この通常版での描画確認はまだ実施していない。再起動後に以前の `loaded.json` が残る場合は、保存してから新しい実行記録を用意する。
4. 通常版で製品ゲームの連続実行と、実行後の画面一致を確認する。
5. 変更した製品用生成スクリプトを最初から実行する確認を行う。検査済み回路と同じ合成・配置・配線設定を記録したが、このスクリプト全体の再実行はまだ行っていない。
6. 結果文書に通常版の確認範囲を追記する。既に有効な90回の比較を、理由なく最初からやり直す必要はない。

## 未解決事項

大きなテクスチャでは公式の命令解析回路に問題があり、512語FIFOでも失敗する場合がある。公式RasterIXの変更はしていない。ブロック崩しの確認済みの画像と、任意の画像が常に正しく描けることを混同しない。

今回のゲーム用DVI出力は、手元のキャプチャでVideo Format Not Supportedとなった。HDMIテスト回路の録画は成功したが、それを通常版ゲームの映像検証と扱わない。ゲームの性能値は画面切り替え完了回数、画面の正しさはメモリ上の全画素比較による。
