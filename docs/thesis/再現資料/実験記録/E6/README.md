# FIFO比較実験と公式更新後の検証

2026年10月8日のFIFO比較実験と通常版の動作検証を収録する。本文13.10〜13.16節と技術付録第29章が、条件と結果、再現方法を説明する。以前のE1〜E5とはソースの版が異なる。

最初に読む記録は、`report/結果と判断.md`である。主比較は90回、再書き込み後の比較は18回であり、二つを混ぜて中央値を計算していない。

| 場所 | 内容 |
|---|---|
| `report/results/runs.csv` | 主比較90回の集計値 |
| `board-v2` | 主比較のフレーム別CSVと実行条件 |
| `board-reconfiguration` | 再書き込み後の18回の集計と各試行の記録 |
| `board-fresh-product` | 新しく生成した通常版の実機確認 |
| `fresh-product/qualification/qualification.json` | 通常版の生成、タイミング、資源、検査の要約 |
| `report/results/video` | 自動プレイの録画、抽出画像、全フレーム検査の記録 |
| `source-update` | 実験時の通常版を親コミットと差分から再現するための記録 |
| `variants` と `scripts` と `measurement-source` | 比較用回路と測定プログラムのソース |
| `report/results/command-parser-reproducer.zip` | 命令解析回路の不一致をFPGAなしで追試する一式 |

このフォルダーで、Python 3を使って次を実行すると、初期状態の全体描画におけるAPB待ち時間の中央値を再計算できる。FPGAやSDカードは操作しない。

```sh
python3 recalculate_wait.py
```

表示は順に、1語方式4.393、16語FIFO2.254、512語FIFO0.465 ms/frameになる。スクリプトは技術付録29.16節の掲載コードと同じものである。

`scripts`には実験時の原本を保存した。実験ルートや接続機器のパスが固定されたものもあるため、別の環境で全てをそのまま実行できるインストーラではない。移植して実行する際は、原本を保ち、コピーの入出力先を自分の環境に合わせる。単体再現ZIPは独立して実行できる。

通常版のソースは、公開コミット`261832d48832dd6e26c4971ab8893ce61200688b`として取得できる。技術付録29.17節に取得手順を示す。公開コミットの995ファイルのハッシュ、11サブモジュールの参照先、親コミットからの全差分が、E6で保存した通常版の記録と一致することを[照合記録](../../../../../publication/console-source.json)に示す。

実験時には未コミットだったため、当時の報告と`source-update`には親コミット`cdf907bc1752b0f300e4fc70b9a51b2bae983b7f`と保存差分を記録している。それらは実験時点の履歴として保持する。公開コミットに保存差分を再適用する必要はない。1語方式、16語FIFO、計測カウンタは実験用の構成であり、通常版に含めていない。

回路生成の大容量ファイルと完全な実験ルートは、元のUbuntuの`/path/to/research/experiments/fifo-study-20261008`に保存されている。この同梱版は、数値の再集計と実装の追跡に必要な記録をまとめたものである。

ブロック崩しの確認結果を、任意のテクスチャ描画や毎回の映像認識の保証へ広げない。大きいテクスチャの不一致と映像認識の不安定さは、未解決事項として本文13.16節に記載した。
