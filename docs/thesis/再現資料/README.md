# 再現資料の使い方

最初に[論文第14章](../本文.md#ch_14)を読みます。既存のリポジトリを変更せず、新しい作業場所で進める手順です。
以下の資料はGitHub上で読めます。[論文と技術付録の入口](../README.md)から説明へ戻れます。

| フォルダ | 用途 |
|---|---|
| [ボード対応](ボード対応/NexysVideo対応を変更前から再現する.md) | 12ファイルの変更前後、差分、順を追った実装演習 |
| [接続ソース](接続ソース) | 論文で扱う主要コードの固定版コピー。ビルドには親リポジトリと全サブモジュールを取得する |
| [試験と測定](試験と測定/README.md) | 実行方法、APB試験、測定ソース、過去データの再集計 |
| [実験記録](実験記録) | 結論と数値の根拠。E1〜E6は論文の資料番号と一致 |

FIFO三方式の比較を読む場合は、[E6の目的と方法](実験記録/E6/report/実験の目的と方法.md)、
[結果と判断](実験記録/E6/report/結果と判断.md)、[使用版と再現用ファイル](実験記録/E6/README.md)の順に進めます。

manifest.jsonでコピー元とSHA-256を確認できます。公開版では測定値を維持し、氏名・個人パス・識別情報を置き換えています。原本とバイト単位で同じではなく、公開版のハッシュはリポジトリのpublication/files.jsonを参照します。過去の計画書にある「今後」や「コミット保留」は当時の状態であり、現在の作業指示ではありません。現在の構成と未検証の範囲は論文を参照してください。

試験ファイルは製品リポジトリへ加えるためのものではありません。SDWire3やOBSを操作する補助コードも、製品の必要条件ではありません。ビットストリームは含めていません。E6には30秒のゲーム映像を含めています。過去に参照した動画などで収録していないものは参照先一覧で区別しています。

ソースの著作権・ライセンス表記はコピー元のものを保持します。公式RasterIXはこの抜粋で改変せず、リポジトリに記録された版をサブモジュールとして取得します。
