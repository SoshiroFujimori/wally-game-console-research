# 再現資料の使い方

最初に論文第14章を読みます。既存のリポジトリを変更せず、新しい作業場所で進める手順です。

| フォルダ | 用途 |
|---|---|
| ボード対応 | 12ファイルの変更前後、差分、順を追った実装演習 |
| 接続ソース | 論文で扱う主要コードの固定版コピー。ビルドには親リポジトリと全サブモジュールを取得する |
| 試験と測定 | 実行方法、APB試験、測定ソース、過去データの再集計 |
| 実験記録 | 結論と数値の根拠。E1〜E5は論文の資料番号と一致 |

manifest.jsonでコピー元とSHA-256を確認できます。公開版では測定値を維持し、氏名・個人パス・識別情報を置き換えています。原本とバイト単位で同じではなく、公開版のハッシュはリポジトリのpublication/files.jsonを参照します。過去の計画書にある「今後」や「コミット保留」は当時の状態であり、現在の作業指示ではありません。現在の構成と未検証の範囲は論文を参照してください。

試験ファイルは製品リポジトリへ加えるためのものではありません。SDWire3やOBSを操作する補助コードも、製品の必要条件ではありません。ビットストリームは含めていません。E6には30秒のゲーム映像を含めています。過去に参照した動画などで収録していないものは参照先一覧で区別しています。

ソースの著作権・ライセンス表記はコピー元のものを保持します。公式RasterIXはこの抜粋で改変せず、リポジトリに記録された版をサブモジュールとして取得します。
