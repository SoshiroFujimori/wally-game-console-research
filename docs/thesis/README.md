## 目的に合わせて読む

仕組みを理解したい場合は、まず[本文第2章](本文.md#ch_2)を読んでください。横位置100の白いボールを103へ動かす例で、位置の変数、画像の色、表示される場所が、どの順に変わるかを図で追います。

次に[第3章](本文.md#ch_3)で、計算する回路と値を覚える回路を組み合わせ、FPGAへ実装する意味を確認します。[第4章](本文.md#ch_4)では、回路を作る作業と、CPUでゲームを実行する作業を分けています。

APB、FIFO、非同期FIFOが分からない場合は、[本文7.1節](本文.md#s_7_1)から順に読みます。番地を指定して値を書くことから始め、三語分の小さなFIFO、二つのクロックをまたぐ問題へ進みます。[付録I](技術付録.md#ch_I)は、その後に内部の管理方法や実装の設定を詳しく確認するために使います。

設計を作り直す場合は、[第14章](本文.md#ch_14)を入口として、[付録E](技術付録.md#ch_E)のボード対応、[付録G](技術付録.md#ch_G)のRasterIX接続、[付録M](技術付録.md#ch_M)の実行手順を使います。

2026年10月8日の改訂では、FIFO比較実験と公式更新後の検証を反映しました。[本文13.10節](本文.md#s_13_10)から、1語方式・16語FIFO・512語FIFOの違い、待ち時間、資源、採用判断を読めます。回路や計測を詳しく追う場合は[技術付録第29章](技術付録.md#ch_29)へ進んでください。

従来の実験E1〜E5とその固定版はそのまま保持し、新しい記録を[実験E6](再現資料/実験記録/E6/README.md)へ追加しました。[目的と方法](再現資料/実験記録/E6/report/実験の目的と方法.md)、[結果と判断](再現資料/実験記録/E6/report/結果と判断.md)もMarkdownで読めます。E6の製品側の更新は未コミットであり、同梱した差分と版の記録を使って再現します。大きいテクスチャの描画問題と、映像認識の不安定さも未解決として記載しています。説明用の数値・回路例と実測値を区別しています。
