# 公開資料の収録範囲

現在の論文本文・技術付録を中心に、それらを読んで実験条件やソースを追える資料を収録しています。
個人情報を含む原本は公開用コピーから分離し、元の保存場所に残しています。

収録したものは次のとおりです。

- 論文本文と技術付録のWord版、Markdown版、図、章別原稿、生成プログラム。
- 論文が参照するE1〜E6の実験条件、測定値、集計、成功・失敗の記録、再現用ソースと差分。
- 補足するRasterIXの数式・RTL検証、Nexys Videoの初期試験、FIFO比較のスクリプト。
- SDWire3の操作・復旧ツールと、当時使ったスクリプトの匿名化した記録。
- E6のゲーム映像。公開前に音声・個人メタデータを除去したもの。

重複する旧版の論文、古い発表草案、個人向けの連絡文、第三者の論文や教科書のコピー、
ローカル環境設定、ビットストリームやディスクイメージ、生成途中のキャッシュは収録していません。
収録範囲外の資料を追加するときも、元フォルダーを丸ごとコピーせず、対象を選んで匿名化します。

過去の報告書は、その時点で得た結果を説明する保存資料です。
最新の構成への適用範囲はE6の報告と論文の説明を参照してください。
公開処理の検査は既存のデータ・文書・ツールに対するものであり、新しい実機実験ではありません。
