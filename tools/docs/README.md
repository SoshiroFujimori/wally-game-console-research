# Technical appendix figures and navigation

All technical appendix chapters are authored under `source/thesis/appendix/`.
The five topic indexes, common index, chapter pages and Word book are built from
the same source. Chapter numbers identify locations, not study priorities.

```bash
python tools/docs/figures.py --check
python tools/docs/appendix_figures.py --check
python source/thesis/build.py 技術付録 --markdown-only --check
python source/thesis/build.py 本文 --markdown-only --check
python tools/docs/navigation.py
python examples/technical-models/explain.py all
```

`figures.py` maintains twelve existing explanatory SVGs; `appendix_figures.py`
maintains eight worked-example SVGs. Both write `source/thesis/figs/guide-*.svg`.
Rasterize edited drawings to PNG, visually review them, and copy SVG and PNG
assets into `docs/thesis/figs/`. Match the established blue, pale blue and black
diagram style. Register reviewed binary hashes only after inspecting pixels.

`navigation.py` validates generated page links and explicit fragment targets.
Per-page contents are generated by the Markdown exporter. To add a chapter,
edit its source and the chapter catalog, then regenerate. Preserve experiment
conditions and source-version qualifications; illustrative numerical models
are not FPGA test results.

Run the publication tests, local privacy audit, reference check and manifest
refresh before committing. Keep the existing commit and push hooks enabled.
