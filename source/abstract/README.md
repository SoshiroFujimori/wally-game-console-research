# Abstract figures

`game-flow.svg` uses pale blue fills to distinguish the board and the chip in
color copies. Text and signal lines remain black. A thick solid border identifies
the FPGA chip; dashed borders identify component sources. These labels and line
styles preserve the distinctions in monochrome printing. Individual components
use white boxes. The drawing is a functional concept diagram; transfer timing is
omitted.

Figure 2 uses the recorded color frame at `docs/thesis/figs/current-game.png`
without a color or tone transformation. Review the circuit diagram in color and
grayscale at its one-column print size, as well as enlarged.
