without changing decoded RGBA pixels. Metadata is stripped by the publication
tool. The highlighting rectangle and callout are separate editable objects
in the PowerPoint. The FPGA is beneath the central heat sink.

## Embedded game video

`breakout-standard-dvi-compatible.mp4` is the distribution encoding used by
slide 12 of the current presentation. It is derived from the already-published
[standard-display recording](../../../experiments/dvi-recovery-20261109/media/latest-standard-dvi-30s.mp4).
The original recording is preserved. The distribution file changes the H.264
profile to High for playback compatibility and retains the same frame order,
1920 by 1080 dimensions, 60/1 frame rate, 1800 frames and 30-second duration.
No overlay, crop, game-state change or retiming is applied. It is a lossy
presentation copy, not a byte-identical experiment original.

[Source hashes and encoding command](breakout-standard-dvi-compatible.json)
identify both files. The PowerPoint embeds the distribution file and starts it
on entry to the demonstration slide. The native PowerPoint player was checked
through the end of the recording. This encoding check is not a new hardware
measurement.
