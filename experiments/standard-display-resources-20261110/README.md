# 標準表示構成のFPGA使用量

ブロック崩しの実機動画で使った回路について、保存済みの配置配線レポートから使用量を確認した。対象はNexys VideoのArtix-7 XC7A200T（xc7a200tsbg484-1）、Vivado 2025.2である。

## 使用量

| 資源 | 使用数 | 搭載数 | 使用率 |
| --- | ---: | ---: | ---: |
| Slice LUTs | 67,166 | 134,600 | 49.90% |
| Slice Registers | 50,890 | 269,200 | 18.90% |
| Block RAM Tile | 215 | 365 | 58.90% |
| DSPs | 61 | 740 | 8.24% |

CPU、バス、DDR制御、描画・表示を含むFPGA全体の値である。各割合は、その資源の使用数を搭載数で割ったもので、種類の異なる割合を合算しない。Block RAMはFPGA内のメモリであり、外付けDDR3を含まない。

## 動画とレポートの対応

レポートの日付は2026年10月8日、状態はPhysopt postRouteである。保存していた検証ディレクトリにある回路設定データと、[2026年11月9日の実機記録](../dvi-recovery-20261109/README.md)に記録された回路設定データのSHA-256は、次の値で一致する。

```text
16173de97a91e711cd7bc5389acd9739807adebedf192efc29fe78f5b96c0acf
```

製品RTLの版は`261832d48832dd6e26c4971ab8893ce61200688b`、公式RasterIXは`9269a01c9bd4c3342bfa70ef8e3cdd751c15c6d0`である。[標準回路のソース確認](../dvi-standard-check-20261108/source-audit.json)と[実機記録の結果](../dvi-recovery-20261109/results.json)も参照できる。ゲーム画面の文字配置の更新はソフトウェアの変更であり、この回路設定データは同一である。

[utilization.rpt](utilization.rpt)は使用量のレポートで、公開時にホスト名と個人用のパスを伏せた。[implementation.json](implementation.json)には、元レポートと公開コピーそれぞれのハッシュ、数値、回路設定データのハッシュ、保存されていた実装検証の要点を記録した。公開コピーは元ファイルとバイト単位で同一ではない。

2026年11月10日に保存済みの記録を取り出して確認した。ここで新たな配置配線や実機試験を実施したわけではない。保存された検証結果はWNS 0.018 ns、WHS 0.014 ns、未制約の内部終点0、配線エラー0、DRCエラー0である。これらは対象構成の記録であり、任意の変更後のタイミングを保証しない。

## 発表での利用

[発表資料](../../docs/presentation/中間発表_主要事項.md#slide-12)の12枚目は、この標準表示構成の使用率を示す。18枚目では、[2026年9月8日のCPU構成の記録](../fpga-resource-comparison-20261108/before-utilization.rpt)をBefore、この標準表示構成をAfterとして示す。

Beforeは、Nexys Video対応時のCPUと周辺回路の構成として保存されたレポートで、回路設定データのハッシュやGitリビジョンは特定できていない。二つの構成でCPUの版や各設定を固定していないため、差を描画回路単体の使用量と解釈しない。比較に使うBeforeの値と元ファイルの来歴は[既存の比較記録](../fpga-resource-comparison-20261108/comparison.json)にある。

[以前の比較記録](../fpga-resource-comparison-20261108/README.md)には実験用の表示構成E8のAfterも残っている。その値を、ここで扱う標準表示構成の値に置き換えず保存する。
